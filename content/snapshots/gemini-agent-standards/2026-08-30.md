Here is a compact digest of the most important distinct items concerning AI agent authentication, web bot auth, agents.txt, llms.txt, or agent identity from the last 30 days:

1.  **IETF Internet-Draft: AAuth Protocol Update**
    The Internet Engineering Task Force (IETF) has seen an update to the "AAuth" protocol, specifically `draft-hardt-oauth-aauth-protocol-10`, published on August 6, 2026. This proposed HTTP authorization protocol for agent-to-resource access aims to replace bearer tokens with signed requests and a cryptographic agent identity, designed to coexist with OAuth 2.0 and OpenID Connect. It assigns every HTTP client its own cryptographic identity, verifiable without pre-registration.

2.  **IETF Internet-Draft: Agent Identity Framework**
    A new IETF Internet-Draft, `draft-sharif-agent-identity-framework-01`, was published on August 26, 2026, focusing on "Agent Identity Framework: Trust and Identity for Autonomous AI Agents." This document defines a framework for agent identity and trust primitives, proposing a layered approach that composes with existing standards where adequate, and outlines gaps where new mechanisms are needed. It addresses the fundamental questions of which agent performed an action, its authorization, and the verifiability of evidence.
    Source: [https://datatracker.ietf.org/doc/draft-sharif-agent-identity-framework/](https://datatracker.ietf.org/doc/draft-sharif-agent-identity-framework/)

3.  **IETF Internet-Draft: OpenID Connect Agent Identity Claims**
    The IETF saw the publication of `draft-sharif-openid-agent-identity-01` on August 26, 2026, titled "OpenID Connect Agent Identity Claims for Autonomous AI Agents." This specification defines a profile of OpenID Connect Core 1.0 to enable Identity Providers (IdPs) to issue identity tokens specifically for autonomous software agents. It introduces standard claims for agent identity, ownership, trust posture, authorized capabilities, and compliance screening status within OpenID Connect ID Tokens.
    Source: [https://datatracker.ietf.org/doc/draft-sharif-openid-agent-identity/](https://datatracker.ietf.org/doc/draft-sharif-openid-agent-identity/)

4.  **IETF Internet-Draft: ApertoID - DNS-Based Agent Identity Declaration Protocol**
    The IETF published `draft-ferro-dnsop-apertoid-02`, "ApertoID: DNS-Based Agent Identity Declaration Protocol," on August 10, 2026. This draft defines a DNS-based protocol allowing domain owners to declare authorized AI agents acting on their behalf, publish cryptographic keys for agent identity verification, and specify enforcement policies. It utilizes existing DNS TXT records under the "_apertoid" domain to provide a decentralized mechanism for agent identity declaration and verification.
    Source: [https://datatracker.ietf.org/doc/draft-ferro-dnsop-apertoid/](https://datatracker.ietf.org/doc/draft-ferro-dnsop-apertoid/)

5.  **W3C Proposed Community Group: Agent Conformance and Benchmarking**
    A new "Agent Conformance and Benchmarking Community Group" was proposed at the W3C on August 25, 2026. This group aims to produce open, reproducible methods for measuring how well web resources and agent systems meet the requirements of autonomous AI agents. Its scope includes developing agent readiness rubrics, runnable conformance suites, and versioned benchmark corpora, acting as a downstream consumer of existing identity, proof, and protocol specifications.
    Source: [https://www.w3.org/community/groups/proposed/#agent-conformance-and-benchmarking-community-group](https://www.w3.org/community/groups/proposed/#agent-conformance-and-benchmarking-community-group)

6.  **IETF WIMSE Working Group: Call for Adoption on AI Agent Authentication**
    The IETF's Workload Identity in Multi-System Environments (WIMSE) working group issued a call for adoption of a draft on AI agent authentication and authorization. This activity, noted on August 28, 2026, indicates progress in formalizing how AI agents prove their identity and are granted access within complex systems, with discussions covering delegation and multi-hop security.

7.  **IETF Internet-Draft: Architectural Requirements for Supporting AI Agents on the Internet**
    `draft-daniel-ai-agent-internet-architecture-00`, published on August 14, 2026, outlines architectural requirements for supporting AI agents on the Internet. This draft addresses the challenges posed by autonomous AI agents, such as dynamic delegation and cross-domain interaction, across various protocol families including authentication, authorization, and delegation. It advocates for profiling and extending existing Internet protocols rather than creating a new monolithic agent protocol.
    Source: [https://datatracker.ietf.org/doc/draft-daniel-ai-agent-internet-architecture/](https://datatracker.ietf.org/doc/draft-daniel-ai-agent-internet-architecture/)

8.  **W3C Working Draft: Linked Web Storage Protocol 1.0**
    The "Linked Web Storage Protocol 1.0" was published as a W3C Working Draft on August 22, 2026. This specification defines a protocol enabling client applications to access and manage web resources based on the identity and permissions of an agent. It outlines mechanisms for identifying agents and end-users interacting with a linked web storage server, leveraging existing standards like OpenID Connect and SAML 2.0 for authentication.
    Source: [https://www.w3.org/TR/2026/WD-lws-1.0-20260822/](https://www.w3.org/TR/2026/WD-lws-1.0-20260822/)

9.  **IETF Internet-Draft: Agent Authorization Use Cases and Gap Analysis**
    An update to `draft-chen-oauth-agent-authz-use-cases-03`, "Agent Authorization use cases and gap analysis," was published on August 25, 2026. This Internet-Draft explores various use cases for agent authorization and identifies existing gaps in current protocols, particularly within the OAuth framework, when applied to autonomous AI agents.
    Source: [https://datatracker.ietf.org/doc/draft-chen-oauth-agent-authz-use-cases/](https://datatracker.ietf.org/doc/draft-chen-oauth-agent-authz-use-cases/)

10. **IETF Internet-Draft: Security Principal and Verifier Binding for Agent Communication Protocols**
    `draft-bu-agentproto-security-principal-binding-06`, "Security Principal and Verifier Binding for Agent Communication Protocols," was updated on August 16, 2026. This IETF Internet-Draft addresses the security aspects of agent communication protocols, focusing on how security principals (agents) are bound to verifiers and the mechanisms for ensuring secure and verifiable interactions.
    Source: [https://datatracker.ietf.org/doc/draft-bu-agentproto-security-principal-binding/](https://datatracker.ietf.org/doc/draft-bu-agentproto-security-principal-binding/)

**Note on llms.txt and agents.txt:**
While `llms.txt` continues to be a topic of discussion and practical implementation for guiding AI models to relevant website content, it remains a community convention and is not an official standard ratified by the W3C or IETF as of the last 30 days. No new or updated standards-body activity on `agents.txt` as a formal standard was found within the specified timeframe.
