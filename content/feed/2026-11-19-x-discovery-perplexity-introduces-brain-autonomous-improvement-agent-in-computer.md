## Summary

Perplexity has launched Brain, an autonomous improvement agent integrated into its Computer product. Brain monitors user sessions to automatically generate and refine personalized, reusable skills. The feature is now accessible to subscribers and reports increases in tool call success rates and overall user satisfaction.

## Key facts

- Perplexity launched an autonomous improvement agent named Brain within its Computer product.
- Brain observes user sessions to create and update personalized reusable skills.
- The system has demonstrated measured improvements in tool call success and user satisfaction.
- Brain is currently available to Perplexity subscribers.
- Perplexity detailed the feature in a blog post at https://www.perplexity.ai/hub/blog/self-improving-skills.

## Insight

AI agent systems are shifting from static prompt libraries to runtime self-reflection, where the system observes user workflows to synthesize and update its own operational tooling without explicit manual configuration.

## Implication

User-delegated agent execution across external web tools and APIs will become more dynamic and persistent, challenging conventional access controls and deterministic bot behavior models.

## Why it matters

As user-facing agents dynamically build custom tool-use capabilities based on session history, tracking automated agent interactions on the web becomes less reliant on predefined tool signatures.
