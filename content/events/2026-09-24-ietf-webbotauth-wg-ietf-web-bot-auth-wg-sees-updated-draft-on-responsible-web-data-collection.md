## Development

An updated revision of the Internet-Draft 'Best Practices for Responsible Web Data Collection' (draft-farzdusa-webbot-datacollection-01) has been published within the [IETF Web Bot Auth Working Group](https://datatracker.ietf.org/group/webbotauth/). The new submission updates the initial version from March 2026, preventing expiration and renewing discussion on operational standards for data collectors.

## Why it matters

Cryptographic authentication verifies who a bot is, but standardizing data collection best practices establishes what behaviors constitute responsible crawling across the web.
